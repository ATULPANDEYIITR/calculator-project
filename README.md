# Calculator Web Application

A responsive calculator web application built from scratch using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Percentage conversion
- Backspace
- Clear button
- Keyboard support
- Calculation history
- Persistent calculation history
- Light mode
- Dark mode
- Error handling
- Divide-by-zero protection
- Responsive design
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Git
- GitHub
